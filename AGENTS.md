# Project direction

Peer-distributed storage and compute are discontinued in this repository.
Do not develop, optimize, expand, integrate, deploy, or propose new work on
the peer storage fabric, replication and custody, distributed scheduling,
checkpoint failover, or distributed execution. Do not reopen this direction
without an explicit new decision from the repository owner.

Existing code and evidence remain as historical research; their presence is
not authorization to continue the project. Documentation and other work that
do not advance the discontinued direction remain in scope. This decision does
not withdraw existing downstream use of Prism ID.

See the project status in `README.md`.
